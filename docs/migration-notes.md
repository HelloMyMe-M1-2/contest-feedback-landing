# PLAN:CHECK 시안 이전 기록

팀이 제공한 ZIP의 HTML과 CSS, 샘플 이미지, Pretendard 폰트를 기준으로 로컬 화면을 구성했습니다. 원본에 포함된 서비스 성능·자문 관련 문구는 팀 검토용 문구로 남아 있으며 실제 사실로 검증되지 않았습니다. 로고 자리 표시는 감췄습니다.

## 구조

- `src/plancheck/original.html`: 원본 화면 마크업. 개인정보를 받는 원본 가짜 완료 폼은 제거했습니다.
- `src/plancheck/Prototype.tsx`: 마크업을 React 요소로 연결하고 측정·신청 폼을 붙입니다.
- `src/plancheck/interactions.js`: 원본 UI 스크립트를 분리한 임시 어댑터입니다. 원본과 완전히 동일한 React 컴포넌트 구조는 아직 아닙니다. 향후 섹션 단위로 이전하면서 이벤트 정리와 컴포넌트 생명주기를 검증해야 합니다.
- `src/components/SignupForm.tsx`: 입력 및 실제 저장 응답 확인. API/D1 미연결 시 오류가 표시됩니다.
- `functions/api/signup.js`: Google Sheets 저장 API. 모의 테스트만 완료했으며 실제 인증과 시트는 미연결입니다. Vite 단독 실행에서는 동작하지 않습니다.

PC에서 샘플 확대, 모바일 390×844 크기에서 첫 화면·메뉴·신청 영역·샘플 확대를 확인했습니다. 실제 휴대기기, 다른 화면 크기, 키보드 조작, 신청 저장 성공의 브라우저-저장소 연결은 아직 확인하지 못했습니다. 로고 자리와 화면 문구는 원본 시안을 따릅니다. 사전 신청 폼은 저장 성공 여부를 확인하도록 React로 옮겼으나 실제 저장 연결은 미완료입니다. 원본에 구매 버튼은 없으며 현재 화면에도 추가하지 않았습니다. 원본의 PC·모바일 프레임 전환 도구는 앱에 옮기지 않았습니다.
