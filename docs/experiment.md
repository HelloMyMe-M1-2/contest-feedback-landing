# 실험 정리

## 목적

아이디어·기획 공모전 참가자가 제출 전 피드백 리포트에 관심이 있는지 탐색한다. 게시글별 조회 200회와 조회 대비 랜딩 유입률 10%는 초기 목표이며 통계적으로 검증된 성공 기준은 아니다.

## 현재 합의

- 링커리어와 에브리타임은 게시 후보이며, 정확한 게시 위치와 일정은 미정이다.
- 구매하기와 관심 등록은 독립 경로다. 실제 피드백, 분석, 결제는 제공하지 않는다.
- 이메일은 연락 목적·관리자·보관·삭제 조건이 정해지기 전까지 수집을 보류한다.
- 구매 버튼 후 서비스와 결제가 준비되지 않았으며 결제나 신청이 완료되지 않았음을 안내한다.
- 가격·제공 범위는 미정이다. 가격 없이 버튼을 제공하면 가격 미제시 상태의 관심으로만 해석한다.
- 리타게팅 광고는 1차 보류다. 팀원이 디자인과 레이아웃을 결정한다.
- 호스팅은 Cloudflare Workers의 정적 호스팅으로 진행한다. 아직 계정 연결·배포는 하지 않았다.
- PostHog를 분석 도구로 검토·연결할 계획이다. 아직 연동하거나 실제 데이터를 수집하지 않았다.

## 측정 원칙

게시글별 유입 비율 = 해당 게시글 ID로 측정된 랜딩 세션 ÷ 같은 기간의 게시글 조회 수. 조회 수는 커뮤니티에서 수동으로 기록한다. 플랫폼마다 집계 기준이 다르고 공유·중복·차단·동의 거부 등이 있으므로 동일인 기준의 비율이 아니다.

구매 클릭은 관심 신호일 뿐 실제 결제나 실제 서비스의 효과가 아니다. 모든 비율과 함께 분자·분모, 관측 기간, 가격 여부와 누락 가능성을 기록한다.

## 공개 전 남은 결정

- 구매 가격과 리포트 제공 범위, 실제 수행 주체와 안내 문구
- 게시 채널의 실제 위치·게시물·기간, 연락 및 운영 책임자
- 분석 수집 항목, 고지·동의 필요성, 수집·보관·삭제 및 수탁·국외 처리 조건
- 최종 화면과 모바일 접근성, 테스트 데이터 분리 및 배포 방법

현직자 검토나 수상 사례는 실제 확인된 이력과 허용된 범위만 표현한다. 회의에서 언급된 복수의 사람의 경력을 한 명의 이력처럼 합치지 않는다.
