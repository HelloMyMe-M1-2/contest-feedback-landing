# 실험 정리

## 목적과 현재 흐름

아이디어·기획 공모전 참가자가 제출 전 피드백 리포트에 관심이 있는지 탐색합니다. 팀이 전달한 현재 시안의 흐름은 **게시글 → 랜딩 방문 → 샘플 리포트 확인 → 이메일 사전 신청**입니다. 구매 버튼은 현재 화면에 없으며 실제 분석·결제도 제공하지 않습니다.

게시글당 조회 200회와 조회 대비 랜딩 유입률 10%는 초기 목표로 제시된 숫자이며 통계적으로 검증된 성공 기준이 아닙니다. 게시 위치와 실험 기간은 아직 정하지 않았습니다.

## 지금 확인된 것

- 팀 시안을 연결한 테스트 화면이 공개되어 있습니다. 실제 참가자 모집은 시작하지 않았습니다.
- 이메일 신청은 로컬에서 가상 신청의 시트 저장을 확인했습니다. 배포된 화면의 시트 연결은 아직 검증 전입니다.
- PostHog에 개발자의 로컬 테스트 기록이 도착했습니다. 실제 방문자 측정은 꺼져 있습니다.
- 이전 시안에서 사용한 구매 클릭 이벤트는 현재 화면의 결과로 취급하지 않습니다.

## 결과를 해석할 때

- **게시글별 유입:** 랜딩에 기록된 게시글 ID별 페이지 방문 수를 봅니다. 현재 실제 실험용 유입 정보 전송은 아직 구현하지 않았습니다.
- **게시글 조회 대비 유입:** 같은 기간의 해당 게시글 랜딩 방문 수 ÷ 커뮤니티에서 별도로 확인한 게시글 조회 수입니다. PostHog만으로 이 비율을 계산할 수 없습니다.
- **신청:** 신청 시작과 저장 성공을 구분합니다. 실제 이메일 목록은 Google 시트에서 확인하며 PostHog 이벤트는 개인정보 없는 행동 기록입니다.
- **중복과 누락:** 게시글 조회 수와 페이지 방문 수를 중복 없는 같은 사람이라고 가정하지 않습니다. 새로고침, 여러 기기, 유입 링크 공유, 브라우저 차단과 전송 실패에 따라 결과가 달라질 수 있습니다.
- **시간:** 화면이 보인 시간과 전체 경과 시간은 다릅니다. 화면 표시 시간도 실제 읽기를 증명하지 않습니다.

이벤트의 구체적인 발생 기준과 분자·분모는 [이벤트 명세](events.md)를 참고하세요.

## 실제 실험 전 남은 일

Cloudflare와 신청 시트를 연결해 가상 데이터로 저장을 확인하고, 실제 참가자용 PostHog 수집 코드와 대시보드를 준비합니다. 팀은 게시글과 실험 기간, 시트 접근 권한, 연락·보관·삭제와 개인정보 안내를 확인합니다. 자세한 순서는 [실험 준비 현황](experiment-readiness.md)에 정리했습니다.
