# 디자인 검토와 도구 선택 기록

> **이전 시안의 검토 기록 · 2026-11-17.** 현재 화면은 이후 팀이 전달한 PLAN:CHECK ZIP을 바탕으로 합니다. 아래의 디자인·구매 버튼 설명은 당시 시안에 대한 기록이며 현재 화면의 설명이 아닙니다. [현재 화면 안내](team-introduction.md)

## 목적과 기준

공모전 참가자가 페이지를 열었을 때 무엇을 위한 서비스인지 이해하고, 가상의 피드백 예시를 살펴본 뒤 구매 버튼의 현재 상태를 오해하지 않도록 하는 것이 목표입니다. 디자인의 완성도뿐 아니라 가독성, 모바일 조작성과 기존 측정 흐름을 함께 확인했습니다.

기존의 밝은 종이 바탕과 녹색 계열을 유지했습니다. 화면을 새로 꾸미는 것보다 기획안과 피드백 내용을 더 쉽게 읽게 만드는 방향을 선택했습니다. 이는 팀 검토를 위한 제안이며, 실제 사용자에게 신뢰를 준다거나 전환율이 개선된다는 검증 결과는 아닙니다.

## 확인한 내용과 한계

- **화면:** 로컬 브라우저에서 1440·1024·768·390px의 첫 화면을 직접 확인하고 320px도 추가로 확인했습니다. 390px에서는 예시 영역도 확인했습니다. 320px에서 페이지 가로 넘침이 없어졌는지도 확인했습니다. 자동화 도구가 모든 크기를 검사했다고 주장하지 않습니다.
- **수치:** 주요 색상 쌍의 명도 대비를 계산했고, 브라우저에서 예시 선택 버튼 44px과 주요 버튼 52px을 확인했습니다. 모든 버튼·상태·브라우저를 망라한 접근성 검사는 아닙니다.
- **기능·측정:** 가상 예시 선택과 구매 준비 중 안내를 확인했습니다. 별도 로컬 실습장에서 페이지 방문, 예시 선택·노출, 구매 클릭이 기록되는 것을 확인했습니다. PostHog 실제 도착 확인이나 실제 참가자 수집은 이번 검증 범위가 아닙니다.
- **코드:** `npm test`와 `npm run build`를 실행했습니다. 이 문서의 검증 결과는 해당 작업 시점 기준이며, 추후 화면 변경 후에는 다시 확인해야 합니다.
- **의도적으로 보류:** 실제 사용자 테스트, 확정 가격·서비스 범위, 팀의 최종 디자인 검토, 외부 서비스 배포는 하지 않았습니다. 로컬 테스트 화면과 실험용 화면을 혼동하지 않습니다.

레이아웃과 문구가 달라졌으므로 같은 이벤트 이름이더라도 이전 로컬 테스트와 결과를 그대로 비교하지 않습니다. 실제 실험을 시작한다면 최종 디자인과 측정 기준, 콘텐츠 버전을 다시 확인해야 합니다.
