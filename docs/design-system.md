# 화면 변경 기준

현재 화면은 팀이 전달한 ZIP 시안의 내용과 구성을 기준으로 합니다. 이전 개발자가 제안한 2026-11-17 임시 스타일은 현재 화면의 디자인 기준이 아닙니다. 해당 검토 과정은 [당시 기록](design-review-2026-11-17.md)에 남아 있습니다.

## 화면을 고칠 때

- 팀의 전달 원본과 최신 결정을 먼저 확인합니다. 내용·레이아웃을 임의로 바꾸지 않습니다.
- 원본 스타일은 `src/plancheck/original.css`, 추가 스타일은 `src/plancheck/prototype.css`에 있습니다. 색상과 폰트를 변경할 때는 실제 적용 범위를 화면에서 확인합니다.
- 모바일과 데스크톱에서 글자 겹침, 가로 넘침, 터치·키보드 조작과 샘플 확대를 확인합니다.
- 버튼의 역할이나 샘플 노출 영역을 바꾸면 [측정 변경 안내](measurement-change-guide.md)와 [이벤트 명세](events.md)도 함께 확인합니다.
- 시안의 서비스 설명과 실제 제공 상태가 혼동되지 않도록 실험 공개 전 팀과 안내를 확인합니다.
